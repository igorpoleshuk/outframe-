# Outframe

Генератор коммерческих предложений для фрилансеров.

Стек: Next.js, TypeScript, Tailwind. Черновики хранятся в `localStorage` — без аккаунта и бэкенда.

## Что внутри

- `/` — лендинг бренда Outframe
- `/studio` — редактор (scope, цена, срок, terms) и live preview; на free — до 2 черновиков
- `/example` и `/p/demo` — публичный пример КП, его можно шарить
- `/p/[id]?d=…` — ссылка клиенту с содержимым предложения
- Print / PDF — через диалог печати; на free лист с водяным знаком, печать не блокируется
- `/pro` — Pro Lifetime 2 490 ₽ разово (основной тариф) или 990 ₽/мес; активация ключа
- `/checkout` — счёт: ссылка на оплату или письмо на почту

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Лицензии

Pro включается ключом `OF-L-…` / `OF-M-…` после проверки на сервере. Секреты и ссылки оплаты — в `.env.example`. Выпустить ключ локально:

```bash
node scripts/issue-license.mjs lifetime
```
