# Ладушки-shop

Магазин модной унисекс-одежды в Бресте.

Стек: Next.js, TypeScript, Tailwind. Корзина в `localStorage`. Заявка без онлайн-оплаты — Европочта или самовывоз.

## Страницы

- `/` — главная бренда
- `/catalog` — каталог с фильтром по категории
- `/product/[slug]` — карточка товара
- `/cart` — корзина и оформление заявки
- `/about` — о магазине
- `/delivery` — доставка, оплата, возврат
